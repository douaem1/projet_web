# CAN 2025 - Morocco 🏆

Welcome to the **2025 Africa Cup of Nations** project, hosted by the Kingdom of Morocco. This interactive web application offers a complete experience to follow one of the continent's largest sporting events.

## 🌟 Project Overview

This project is a modern web platform designed to inform fans about CAN 2025. It brings together essential information about stadiums, qualified teams, the match schedule, and the history of the competition.

## 🚀 Key Features

- **Interactive Countdown**: Track the time remaining until the kickoff on December 21, 2025.
- **Stadium Exploration**: Discover Morocco's architectural gems (Grand Stade d'Agadir, Ibn Batouta Stadium in Tangier, Moulay Abdellah Complex in Rabat, etc.).
- **Schedule & Teams**: Consult the match calendar and qualified teams (Atlas Lions, etc.).
- **Archive Section**: Relive the highlights of previous editions (CAN 2021 in Cameroon and CAN 2023 in Ivory Coast).
- **Multilingual Interface**: Support for French, Arabic, and English.
- **Responsive Design**: A fluid experience on desktop, tablet, and mobile.

## 🛠️ Technologies Used

- **HTML5**: Semantic structure and content.
- **CSS3**: Modern design, fluid animations (glassmorphism, hover effects).
- **JavaScript**: Interactive logic (countdown, language switching, slider, navigation).

## 📁 Project Structure

```text
├── accueil.html            # Main home page
├── matches.html            # Match schedule
├── equipe_qualifiée.html    # List of teams
├── [Stades].html           # Individual pages for each stadium
├── accueil.css             # Main styles
├── accueil.js              # Home page logic
├── images/                 # Photo gallery and logos
└── videos/                 # Multimedia content
```

## 💻 Installation and Usage

1. Clone or download the repository.
2. Open the `accueil.html` file in your preferred web browser.
3. Explore the different sections via the navigation bar.
